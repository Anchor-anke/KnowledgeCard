# KnowledgeCard CAPM MVP

这是按照 `docs/module-design.md` 搭建的 CAPM 学习小程序后端领域核心 MVP。当前版本使用 Python 标准库和内存基础设施，重点先验证业务边界与端到端流程；存储、微信和 AI 都通过适配器隔离，后续可以替换为真实实现。

## 已实现模块

- 身份与用户：微信身份映射、引导、学习目标、学习量和订阅设置。
- 考试内容目录：CAPM 知识点建模。
- 内容工作流：草稿、AI 初稿、审核、发布、下架、恢复、版本和审计。
- 卡片交付：用户端只读取已发布版本。
- 学习记录：卡片完成、自评幂等、修正记录和事件。
- 复习计划：版本化透明规则、逾期识别、知识点级合并。
- 内容反馈：错误/难懂/重复反馈、短期去重和处理。
- 提醒：每日汇总、订阅授权门禁、发送失败不影响复习。
- 埋点分析：领域事件最佳努力记录。

## 运行测试

项目不依赖第三方包，使用 Python 3.9+：

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

测试覆盖新用户闭环、未发布内容隔离、三档自评、幂等和修正、到期复习优先、逾期合并、内容权限状态机、版本、AI 草稿、反馈、提醒和关键事件。

## 边界说明

这是可运行的领域 MVP，不包含真实微信小程序页面、HTTP 框架、生产数据库和真实 AI 供应商凭证。它们应分别接在 `KnowledgeCardApplication` 外层、repositories 和 AI/微信 adapter 上，不能绕过领域服务直接修改业务状态。
